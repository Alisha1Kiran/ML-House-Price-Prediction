# ML-House-Price-Prediction
This project is a simple Machine Learning model that predicts house prices based on features like: 
Size (square feet) 
Number of bedrooms 
Age of house

The goal of this project is to understand the basics of:
Regression models
Model evaluation (MSE, R² Score)
Making predictions using trained models

Technologies Used:
Python
Pandas
Scikit-learn

Model Used:
Linear Regression

Steps Performed:
Data Loading - Loaded dataset using Pandas
Data Preprocessing - Selected relevant features (Area, Bedrooms, Bathrooms)
Split data into training and testing sets
Model Training - Used Linear Regression model from Scikit-learn
Model Evaluation - Mean Squared Error (MSE): 884,473,912 AND R² Score: 0.91
